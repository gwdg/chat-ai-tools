Chat AI Browser Control

This extension connects to a local MCP relay. The relay lets Chat AI ask for browser access; you approve every tab in a confirmation window.

Setup

  1. Start the relay: npm run mcp:chromium.
  2. It prints the extension WebSocket URL, normally ws://127.0.0.1:8766/extension.
  3. Paste that URL above and choose Save and connect.
  4. Add the printed MCP endpoint to Chat AI: http://127.0.0.1:8766/mcp.

If the relay sets MCP_CHROMIUM_TOKEN, configure Chat AI to send Authorization: Bearer <token>. That token is separate from the optional extension token above.

The extension can read and control tabs only after you approve each tab. Session approvals are stored in memory for the current browser session and can be revoked from the toolbar popup.
