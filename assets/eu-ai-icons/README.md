# EU AI-generated content icons

These files are the official EU icons for labelling fully AI-generated content.

Source:
<https://digital-strategy.ec.europa.eu/en/policies/eu-icons-labelling-ai-generated-content>

Downloaded from the official SVG ZIP:
<https://ec.europa.eu/newsroom/dae/redirection/document/129546>

Files:

- `label-ai-generated-black.svg` — black badge for light backgrounds
- `label-ai-generated-white.svg` — white badge for dark backgrounds

The European Commission publishes these icons for everyone to use freely,
without attribution to the Commission or the AI Office. Using them does not by
itself establish compliance with Article 50 of the AI Act. See the source page
for the placement guidance and limitations.
